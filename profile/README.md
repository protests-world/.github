A live, open, anonymous map of what the world is protesting — and how the mood shifts.

- An X-style live feed beside a 3D OpenStreetMap globe that glows where people raise their voices.
- **Anonymous by design** — no accounts, coarse-only location, no IPs stored against content.
- **Open feed, earned map** — every voice shows; map prominence is corroborated, never bought.
- **Open source (AGPL-3.0)**, ad-free, and built to run on free tiers.

> Building in the open — not yet live to the public.
